# そのとき

「牛乳を買う」「帰ったら書類を確認する」といったメモを、必要な場面で表示する体験を検証するWebプロトタイプです。

ReactとTypeScriptで、メモの入力から状況に応じた表示、完了・再通知までを実装しています。現在の文章解析は日本語のキーワードに基づくルールベースです。

**開発状況:** Webプロトタイプとして開発終了。SwiftUI版は検討・試作後に開発を中止しています。

## 試せること

1. 思い出したい内容をメモとして入力する
2. 提案された状況を確認し、必要に応じて場所を登録する
3. 画面上で帰宅・外出・店舗への到着などをシミュレーションする
4. 表示されたメモを「やった」で完了、または「次のそのとき」で次回の同じ状況まで保留する

「次のそのとき」は、一定時間後の再表示ではなく、同じ状況が次に成立したときの再表示を扱います。

## 実装上の工夫

文章の解釈と条件の判定を分け、画面とは独立して検証できる構成にしています。

| 層 | 役割 | 実装 |
| --- | --- | --- |
| Interpreter | 日本語のメモから状況の候補を作る | `web/src/domain/interpreter.ts` |
| Resolver | 状況を時間・到着・退出の条件へ変換する | `web/src/domain/resolver.ts` |
| Trigger engine | 状況の変化に応じてメモの状態を更新する | `web/src/domain/engine.ts` |
| Place dictionary | 場所の呼び方と登録された場所を対応付ける | `web/src/domain/placeDictionary.ts` |

## 実装範囲と制約

- Web版は画面上の状況シミュレーションで体験を検証します。実際のバックグラウンド位置監視を再現するものではありません。
- 自然文の解析はルールベースであり、LLMによる推論はWeb版に実装していません。
- 判定が曖昧な入力や未登録の場所は、利用者による確認・登録を必要とします。
- `ios/` にはSwiftUI版の試作コードとSwiftパッケージを残しています。

## 起動方法

Node.jsのバージョン指定は[.nvmrc](.nvmrc)を参照してください。

```bash
cd web
npm ci
npm run dev
```

## 検証用コマンド

```bash
cd web
npm test
npm run lint
npm run build
```

ドメインロジック・ストアのテストは `web/src/domain/` と `web/src/store/` に配置しています。
